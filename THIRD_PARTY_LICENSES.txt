Scope
-----
This note summarizes direct Python dependencies declared by the repository. It is
not a complete software bill of materials, a review of every transitive build or
test dependency, or a legal or security certification. Distribution contents and
environment-provided components may require separate inspection.

Runtime
-------
The current project metadata declares no additional Python runtime packages.
The application uses the Python standard library and SQLite supplied by the
Python runtime. No third-party Python runtime dependency is listed in
pyproject.toml.

Build and development
---------------------
The build-system declaration in pyproject.toml requires hatchling>=1.25.
Test and lint tools are used in the development/CI context; they are not
application runtime dependencies. Their complete transitive dependency and
license inventory is outside the scope of this note.

Repository facts
----------------
- The application stores notes in local SQLite and plain-text notebook files.
- The optional web interface binds to loopback.
- The process does not require administrative elevation and inherits the
  permissions of the process that launches it.
- These facts do not establish an operating-system egress block, sandbox,
  complete dependency inventory, or independent security certification.
